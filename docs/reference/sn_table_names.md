# Schedule N table names in the NCCS efile release

Schedule N table names in the NCCS efile release

## Usage

``` r
sn_table_names()
```

## Value

A named character vector (short name = canonical table).

## Examples

``` r
sn_table_names()
#>                                        p1_header 
#> "SN-P01-T00-LIQUIDATION-TERMINATION-DISSOLUTION" 
#>                                        p1_assets 
#> "SN-P01-T01-LIQUIDATION-TERMINATION-DISSOLUTION" 
#>                                        p2_header 
#>               "SN-P02-T00-DISPOSITION-OF-ASSETS" 
#>                                        p2_assets 
#>               "SN-P02-T01-DISPOSITION-OF-ASSETS" 
#>                                          p3_text 
#>                   "SN-P03-T99-SUPPLEMENTAL-INFO" 
```
