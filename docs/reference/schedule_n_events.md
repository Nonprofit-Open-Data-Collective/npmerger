# Schedule N involvement by organization and year

Schedule N involvement by organization and year

## Usage

``` r
schedule_n_events(sched_n, transactions = NULL)
```

## Arguments

- sched_n:

  The `sched_n` table (filers).

- transactions:

  The `transactions` table (named recipients).

## Value

A data.table of unique `EIN2`, `TAX_YEAR`.
